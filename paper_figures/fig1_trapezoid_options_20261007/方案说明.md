# 图1梯形虚线展开候选方案

本轮仅修改 DLinear 专家组与内部结构之间的展开边界。图中所有文字、公式、模块位置、计算箭头、示意曲线、色块及居中的加号均保留。

| 方案 | 表现方式 | 使用建议 |
|---|---|---|
| A | 上下实线框，两条虚线斜边构成梯形展开关系 | 优先推荐，边界清楚且较简洁 |
| B | 梯形上、下边与斜边均为虚线 | 更强调完整的梯形展开区域 |
| C | 虚线连接点向内收，线条稍细 | 展开关系更轻，适合希望减弱边界存在感的情况 |

- 公式字符最小字号：5.25 pt；PDF 文字尺寸核验通过。
- PDF 碰撞检查：三版均为 0 个错误、0 个警告。
